# Nakshatra

Sinhala, Tamil and English astrology and almanac app for Sri Lanka — daily horoscope, nekath (auspicious timings), rahu kalaya, panchanga, birth charts and porondam compatibility.

All astronomical calculations run **on-device**. No birth data is uploaded to any server.

> For entertainment purposes only.

## Status

Early development. Not yet released.

## Requirements

| Tool | Version |
| --- | --- |
| Flutter | 3.41.x (stable) |
| Dart | 3.11.x |
| JDK | 21 |
| Android SDK | 37.0.0 |

Verify with `flutter doctor -v` before building.

## Getting started

```bash
git clone https://github.com/chamod-ishankha/helacode-nakshatra.git
cd helacode-nakshatra
flutter pub get
flutter run
```

## Configuration

The following files are **not** in version control and must be supplied locally.
Nothing in this list should ever be committed.

| File | Purpose |
| --- | --- |
| `android/key.properties` | Release signing credentials |
| `android/app/google-services.json` | Firebase Android config |
| `lib/firebase_options.dart` | Generated by FlutterFire CLI |
| `.env` | API keys — see `.env.example` |

`android/local.properties` is generated by Flutter and is also ignored.

## Project layout

```
lib/
├── core/        theme, router, constants, error handling
├── features/    feature-first modules (data / domain / presentation)
├── shared/      cross-feature widgets and utilities
└── l10n/        Sinhala, Tamil and English translations
```

## Building

```bash
flutter analyze
flutter test
flutter build appbundle --release
```

Note: `gradlew` and `gradle-wrapper.jar` are intentionally not tracked (Flutter's
default ignore rules). Build through `flutter build`, which regenerates them —
do not invoke `./gradlew` directly on a fresh clone.
